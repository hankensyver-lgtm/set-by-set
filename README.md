# Set by Set

A workout planner that runs in the browser.

1. **Set up:** pick your equipment, the muscle groups to train, how long and how hard.
2. **Plan:** review the generated plan. Swap, remove, add or reorder exercises and change sets, reps and rest.
3. **Train:** tap sets to cross them off. Rest timers and timed sets (planks, intervals, stretches) run automatically, with beeps.

Everything is in `index.html`. It has no build step and no server. Your plans and history are saved in your browser's local storage on each device.

## Hosting on GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → Save.
The site will be at `https://<your-username>.github.io/<repo-name>/`.
